### Dominion
**Multi-Agent AI for Real Estate Intelligence**

Multi-agent system that combines property data, zoning information, vector search, and AI reasoning to produce evidence-backed real estate recommendations.

Built with Amazon Bedrock AgentCore, Lambda, Aurora PostgreSQL, pgvector, React, and TypeScript.

[Demo](https://youtu.be/DInd-qoBMnk)

`Python` `AWS` `AI Agents` `PostgreSQL` `pgvector` `React`
